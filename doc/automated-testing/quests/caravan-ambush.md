# Caravan Ambush (#3775)

This quest uses `Issues/Framework` and `Issues/Quests/CaravanAmbush`. The server creates the destination, bait caravan, raiders and three trade-good rewards. Only the accepting client starts the quest and registers its dialogue. Server event dispatch runs the unstarted quest as its owning player, with patches active.

Duplicate and similar-commitment checks belong to the framework introduced by #3943. There is no quest-specific duplicate gate. The quest retains vanilla's relation, faction and troop checks. Its stay-alive patch checks for the giver's caravans; the framework checks war through `CanPlayerTakeQuestConditions` as the requesting player. Conversation tracking from #3768 is no longer part of this framework's accept path, so that patch is not needed here.

## Source used

Installed Native module: v1.4.8. `TaleWorlds.CampaignSystem.dll` SHA-256: `1F8E33E2ED73E6EC653D7629180AFB70649DDC6E5BD1657A802A264EFDA1C3AE`.

The full local decompilations are retained in `artifacts/caravan-vanilla.cs`, `artifacts/quest-base.cs`, `artifacts/issue-base.cs`, `artifacts/quest-manager.cs` and `artifacts/campaign-events.cs`. They are local diagnostic artifacts, not repository source. Relevant vanilla methods are `OnQuestAccepted`, `HourlyTick`, `MapEventStarted`, `MapEventEnded`, `OnQuestSucceeded`, `OnPlayerHiredBandits`, `OnFailedVicinityChecks`, `OnCaravanDestroyed`, `OnCaravanSurvivedWithoutHelp`, `OnSettlementEntered`, `OnWarDeclared`, `OnClanChangedKingdom` and `OnTimedOut`.

Vanilla offers direct and companion solutions (`IsThereAlternativeSolution = true`), and explicitly has no lord solution (`IsThereLordSolution = false`). It has no persuasion or bribe dialogue. Hiring the quest raiders is a separate success path. The companion solution has failure risk and casualties, requires tier-2 troops, and uses Tactics or Roguery at 120. Its success adds Scouting and combat skill XP, three renown and five relation; failure removes five relation and five giver power. The framework owns its roll, troop state, return and owner substitution.
